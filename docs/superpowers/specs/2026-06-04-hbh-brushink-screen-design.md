# 第四屏「笔墨课徒」设计规格 · 五笔七墨语法谱

---

## 1. 背景与定位

`HBH.html` 现为三屏「数字黄宾虹」展示 deck（顶部自动隐藏导航切换、各屏懒加载 IIFE）。本规格新增**第四屏：黄宾虹的画法（笔墨技法）**。

与既有三屏的边界（避免重复）：
- 第二屏「实景山水」已点到白宾虹→黑宾虹、浑厚华滋、1933 入川变法——那是**作品与生平叙事**。
- 第三屏「交游长河」是**师友互动**。
- 第四屏要往**笔墨技法本身**钻：他怎么一笔一墨把山画成"黑、密、厚、重"，以及这套手法的**名目与法度**。

### 关键设计判断（本页推倒重来后的立足点）

最初讨论过三个机制——真迹显微镜、图层剥离时光机、实时 RAG 书童——**全部作废**，原因是它们都试图展示画的**物理秘密**（笔触叠了几层、墨怎么渗、宣纸纤维），而这恰是本项目**没有、也无法诚实复原**的：

1. **无真实分层数据**：黄宾虹传世只有成品，没有任何"第几层"的历史笔层。任何"剥离"都只能是重构／想象，把它冒充某名作的真实图层会踩"编码诚实"红线。
2. **分辨率不足**：`assets/works/` 共 64 张，最大约 818×1080 / 857×2000（立轴竖图）。3× 放大放出来是 JPEG 糊点，撑不起"暴露笔触"的承诺。
3. **离线单文件**：禁外部库／CDN，graphrag 后端未接前端，页内做不出真·实时 RAG 问答。

掉头方向：**不展示物理秘密，展示思想秘密。** 黄宾虹是把中国画笔墨"讲明白"讲到极致的人——他的画论原话、金石出身、亲手编定的术语体系（五笔七墨），是我们能 100% 诚实拥有的真资产。"画法"的**法**在他那里本就是可言说、可教的**法度**。把一套口传心授的笔墨语法做成人人能读懂的东西，正是数字人文最该做、也最做得好的事。

## 2. 核心感悟（三类受众，每人都要带走一句）

- **大众**：原来"笔墨"不是一团黑、不是一句空话——它是 12 种有名有姓的手法；认得了，我再看他的画就能"读"出门道。
- **人文学者**：五笔七墨的完整术语体系，配宾翁原话与真迹例证，且笔法溯源金石书法。
- **IEEE VIS 审稿人**：手绘演示＝教学图示（明标）、真迹缩图＝真图、引文＝宾翁原话且出处可注——编码诚实，真／拟可辨。

---

## 3. 红线与约束（沿用全 deck 统一风格）

- **配色**：矿物国画色，暖宣纸底＋赭红 accent，六圈层矿物色系；禁纯白、禁花哨彩虹、禁全褐发闷。沿用第三屏 `#hbh-river` 的 CSS 变量与调性。
- **纹理**：宣纸／绢颗粒（SVG feTurbulence）＋纤维纹。
- **字体**：衬线（Noto Serif SC / Songti）。**界面禁出现英文。**
- **实现**：纯手绘 SVG/Canvas；**禁 ECharts、禁外部库/CDN**（离线单文件）。
- **文案**：人文学者评析口吻、有历史感；并给"草草看两眼"的人一句大白话提要；绝不 AI 公式化。
- **诚实**：我们手绘的笔触／渍墨演示一律明标"笔法／墨法示意·教学图示"；真迹缩图与"读画"用的是真画；五笔七墨定义引宾翁原话、出处可注。

## 5. 详细设计

### 5.1 题头

- 章序＋标题：「数字黄宾虹 · 第四章 / 笔墨课徒」（命名见 §9）。
- 一句大白话提要（给草草看的人）：例如"中国画的高下，全在一笔一墨之间。黄宾虹把它拆成了十二个字。"
- 一句宾翁**定调原话**（引真话，出处可注）：如"画有笔墨，方能成家"一类（最终引文以核实为准，见 §6）。

### 5.2 进一 · 识字谱

布局：**左谱 + 右焦点区**。

- **左·笔墨谱（课徒谱／印谱式格子墙）**：12 个字-格，上半五笔（5 格）、下半七墨（7 格）。每格仅大字＋一个极简手绘笔触/墨痕缩影＋一句比喻（如"平·如锥画沙"）。整墙信息密度高但不挤（每格小）。hover/点击切换右侧焦点。
- **右·焦点区（案头／临池）**：显示当前字的：
  - **动态演示**（诚实装置，见 §5.4）；
  - **宾翁原话定义**＋出处；
  - **一张真迹缩图**＋一句"去这幅里找它"；
  - 若为五笔，附**金石根**：一行引子＋一张金石图（古籀篇／东池印集），点出"这套笔从刻印写篆来"。
- 默认焦点＝首格「平」，焦点区永不空白。

### 5.3 进二 · 读一幅画

- 一张晚期黑宾虹真迹满铺（候选见 §6.4，不放大、不分层，仅满铺展示）。
- 12 字变为可点**标签栏**（rail）。点任一字 → 画面上"用到该法"的若干区域被**圈注＋连线＋短注**点亮；可多选；含"全标"一键铺满。
- 区域标注为人工策展数据（见 §6.4），明确是"指认该法在此出现"，非像素级证据。

### 5.4 一格的诚实装置（核心）

- **五笔（手绘动态笔触，SVG path 描边动画）**：把这根线"写"出来——
  - 平＝如锥画沙（匀力中锋、不漂浮）；
  - 圆＝如折钗股（圆转无圭角）；
  - 留＝如屋漏痕（顿挫、留得住、墨痕渐渗）；
  - 重＝如高山坠石（起笔重按）；
  - 变＝诸笔互参、随机应变。
  - 每格明标"笔法示意·教学图示"。
- **七墨（一方空白"宣纸格"里 Canvas/SVG 渍染演示）**：浓、淡、破墨（两笔相破趁湿渗）、泼墨（大块泼洒）、积墨、焦墨（干枯浓黑）、宿墨（隔宿渣滓、墨晕外溢）。
- **积墨那一格 = "叠加遍数"微动画**：1 遍→5 遍→20 遍，看着一处由淡变浓、由薄变厚。这把用户最初"积染叠几十遍的魔术"那个最打动人的直觉**以诚实方式找回**——区别在于：它在一方**空白示意格**里演示技法，不冒充任何真画的真实分层。
- 全部手绘演示统一带"示意·教学图示"角注，与真迹缩图在排版上可辨。

### 6.2 真迹佐证归类【需策展】

把 `assets/works/` 64 张按笔墨法归类，每字配 1 张最能体现该法者：
- 晚期（湖山爽气图 1951／晓望图 1950／南岳山水图 1953）→ 积墨、焦墨、宿墨、重墨；
- 早期疏淡作 → 淡墨、留笔；
- 蜀游图／嘉陵山水 → 写生转折、破墨。
- **不放大、不分层**，仅"这幅明显用了它"的指认，现有分辨率够用。

### 6.3 金石根图

挂 `古籀篇` / `东池印集` / `滨虹草堂藏古玺印` 等真·金石资产（目前在 deck 中闲置），作五笔半边的"原来如此"引子。

### 6.4 读画真迹 + 区域标注【需策展】

- **候选主图**：晚期黑宾虹中笔墨语汇较全者，如 `湖山爽气图` / `晓望图`（构建时择分辨率与构图最佳者定一张）。
- **区域标注数据**：人工标出画面若干区域（多边形或锚点坐标）→ 绑定笔墨字 + 一句短注。是策展指认，非像素级证据，措辞需诚实。

## 10. 范围与非目标（YAGNI）

**做**：识字谱（12 格＋焦点区＋手绘演示＋原话＋真迹缩图＋金石根）、读画态（真迹＋标签栏＋圈注连线）、两态切换。

**不做**（明确排除，因与约束/诚实冲突）：
- 像素级真迹显微镜（分辨率不支持，过承诺）；
- 真画的图层剥离/分层（无真实分层数据，会伪造）；
- 页内实时 RAG 书童（离线、后端未接）——全站聊天若需要，复用已有 `#hbh-sprite` 小像浮窗，不在本页另起。
